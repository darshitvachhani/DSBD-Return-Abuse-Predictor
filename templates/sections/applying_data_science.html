Algorithms & Sketch Methods Deployed
1. Unstructured NLP Transformation

TF-IDF feature extraction on free-text return reasons (strictly fit on train set to prevent data leakage).

2. Predictive Classifiers

Parametric Logistic Regression, CART Decision Tree, Random Forest (Bagging + Feature Subsampling), and Bagging Ensembles.

3. Policy & Segmentation

Asymmetric Cost Optimization Curve (CFP ≠ CFN) and Multi-Dimensional K-Means Clustering for policy routing.

Model Predictors & Engineered Features
Customer Profile Signals
  • Customer Lifetime Return Rate
  • Account Age (in days)
  • Device Signals (Desktop/Mobile/Tablet)
Transaction Dynamics
  • Order Value (£)
  • Days Between Delivery & Return
  • Discount
  • Payment Method
Merchandise & NLP Text
  • Category Mix (Apparel/Electronics/Home)
  • Free-Text Return Reason (Raw String)
The Core Asymmetric Decision Dilemma

A naive binary cutoff at 0.50 ignores operational reality: False Positives (falsely accusing a loyal high-LTV customer of fraud) alienate high-value shoppers (CFP = £50), whereas False Negatives (allowing an abusive return to pass uninspected) costs the company reverse shipping and inventory write-off (CFN = £25). The platform balances these asymmetric costs through calibrated machine learning decision boundaries.
