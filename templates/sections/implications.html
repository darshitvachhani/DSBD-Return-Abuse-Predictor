1. Threshold Calibration & Trade-Off Dynamics

Standard machine learning setups apply an arbitrary 0.50 cutoff. In retail operations, this is sub-optimal:

  • Lowering the cutoff (< 0.50): Catches more fraudulent returns (higher Recall) but increases wrongful friction on regular shoppers (more False Positives).
  • Raising the cutoff (> 0.50): Eliminates friction for prime customers (higher Precision) but permits sophisticated abusers to exploit free returns (more False Negatives).
  • Optimal Policy: Operating at the cost-tuned threshold of t* = {{ data.opt_thresh }} balances these penalties to minimize total operational loss.
2. Feature Drivers & Behavioral Takeaways

Tree-based feature importance consistently highlights three dominant operational risk factors:

  • Consecutive Prior Returns: The single strongest predictor of abuse. Customers exceeding 3–4 back-to-back returns display systemic bracketing or wardrobing behavior.
  • Order Value & Return Delay: High basket totals returned near the end of the return window represent significant inventory depreciation risks.
  • Unstructured Reasons: Vague text descriptions combined with high return velocity serve as an early indicator of return abuse.
